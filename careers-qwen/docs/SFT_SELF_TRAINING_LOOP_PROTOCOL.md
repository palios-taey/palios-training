# SFT self-training loop (design-only protocol)

This protocol binds the existing SFT standards to Jesse's production loop. It
creates no rows and does not authorize a launch. Current baseline: zero eligible
full multi-turn orchestration and Git trajectories; UI capture is also held
until the producer event contract lands.

## Executable cycle

1. **Real attempt.** Taey performs the scoped production task under the live
   tool contracts. Supervisors provide scope and authority, not a scripted tool
   sequence.
2. **Exact capture.** Record the request, every model proposal, tool name,
   arguments, call ID and order, exact result bytes, and validation/closure
   receipts in the supervised capture contract. A missing event is a full stop.
3. **Self-report.** Taey states what it believed, what it could not establish,
   and where the attempt diverged. This is evidence, not a target row.
4. **Diagnosis.** An optional neutral non-Claude Chat consultation may classify
   the capability gap or infrastructure defect. Chats diagnose curriculum and
   mixture/dose; they do not author synthetic trajectories or override live
   contracts.
5. **Corrective attempt.** Taey performs a fresh supervised production attempt
   with the same scope. The supervisor does not choose tool calls for it.
6. **Admission.** Only a production-observed right-way sequence with complete
   provenance, live-contract validation, and independent post-state evidence
   can become an SFT pair. Failure material is excluded unless the governed
   format explicitly permits it and the residue/privacy/quarantine gates pass.
7. **Promotion authority.** Treasurer sanctions the corpus. Chats approve
   mixture and dose. No seat infers those approvals.
8. **Training and re-evaluation.** Train only through the production recipe,
   then repeat the same-class production task. Promotion requires the real lane
   to improve without violating base, provenance, or safety gates.

## Invariants

No reconstructed history, generic Q&A, autonomous preprogrammed trajectory,
private-data export, or supervisor-authored answer. Weight movement proves that
training ran, not that the capability improved; production behavior is the
oracle. A zero eligible count remains the honest result until complete captures
exist.
